# 提交前检查清单

提交前按以下清单自查。

## 基本信息

- [ ] 已准备最终报告 PDF 附件。
- [ ] PDF 文件名符合 `姓名_基础题_大题_report.pdf`。
- [ ] 已写明姓名、年级专业、基础题和大题。
- [ ] 已附上题目链接。
- [ ] 已附上基础题仓库链接和大题仓库链接。
- [ ] 已说明基础题和大题分别使用的机器环境。

## 基础题

- [ ] 已选择 HPL 或 HPCG 中的 1 个。
- [ ] 已跑通基础题 Baseline。
- [ ] 已保存基础题运行命令、日志和结果。
- [ ] 已记录基础题机器环境。
- [ ] 已至少测试 3 组参数或配置。
- [ ] 已说明基础题中表现最好的一组参数或配置。

## 大题

- [ ] 已选择 1 个大题。
- [ ] 已跑通大题 Baseline 或官方示例。
- [ ] 已保存大题 Baseline 运行命令。
- [ ] 已保存大题 Baseline 日志。
- [ ] 已记录大题 Baseline 运行时间。
- [ ] 已记录大题正确性或输出质量结果。
- [ ] 已记录大题机器环境。

## 优化与对比

- [ ] 已说明大题主要瓶颈或改进点。
- [ ] 已完成大题要求数量的优化或工程改进。
- [ ] 已保存优化后运行命令。
- [ ] 已保存优化后日志。
- [ ] 已记录优化后运行时间。
- [ ] 已验证优化后结果仍然正确。
- [ ] 已对比 Baseline 与优化后结果。

## 仓库整理

- [ ] 相关仓库中有结果记录，或报告中贴出了关键结果。
- [ ] 相关仓库中有关键日志，或报告中贴出了关键日志。
- [ ] 运行命令和复现方式说明清楚。
- [ ] 大型数据、模型权重、临时缓存没有直接提交到仓库。
- [ ] 报告中的命令、日志和结果文件能互相对应。

## 最终确认

- [ ] 最终报告 PDF 已作为邮件附件。
- [ ] 收件邮箱为 `dotredstone0123@gmail.com`。
- [ ] 邮件标题严格符合 `ASC选拔作业-姓名-基础题-大题`。
- [ ] 邮件标题没有额外空格、括号、学号或其他文字。
- [ ] 邮件正文严格使用指定格式。
- [ ] 邮件附件只有 1 个 PDF 报告。
- [ ] 基础题仓库和大题仓库已经推送。
- [ ] 基础题仓库和大题仓库已经设置为 Public，链接可直接访问。
- [ ] 报告内容能够由本人解释。
